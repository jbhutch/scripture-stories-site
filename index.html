Put a scripture story on your iOS Home Screen

A free app called Scriptable can run a small script that pulls a random story from this site's API and draws it as a Home Screen widget. It picks a new story roughly every hour, so you get a different one through the day without opening anything.

Choose the Large widget size.

This is the one thing worth getting right. The widget shows the story's summary, and only the large size has room for it:

  • Small — no summary at all, just a title and reference.
  • Medium — the summary is cut off after a line or two, usually mid-sentence.
  • Large — the full summary fits. This is the one to use.

iOS won't let you resize a widget after you've placed it. If you add the wrong size, remove it and add it again.

Before you start

  • An iPhone or iPad running iOS 14 or later.
  • The free Scriptable app from the App Store.
  • About five minutes.

Step 1 — Add the script to Scriptable

Easiest if you do this on the iPhone or iPad the widget is going on, so the script is already on the clipboard when you get to Scriptable.

  1. Tap Copy the whole script below.
  2. Open Scriptable.
  3. Tap the + in the top-right corner to start a blank script.
  4. Tap and hold in the editor, then tap Paste.
  5. Tap the script's name at the top of the editor and rename it Scripture Stories — you'll pick it from a list later, so give it a name you'll recognise.
  6. Tap Done.

Tap the script's play button now to check it works. It should show a story rather than an error.

View the script scripture-stories-widget.js

You don't need to select any of this by hand — the button above copies all of it. If you'd rather do it manually, tapping the code once selects the whole thing.

Download the file instead, if you prefer.

Step 2 — Add the widget to your Home Screen

  1. Go to your Home Screen and press and hold on any empty space until the icons start to jiggle.
  2. Tap + in the top-left corner. (On iOS 18 and later, tap Edit first, then Add Widget.)
  3. Search for Scriptable and tap it.
  4. Swipe across to the large square preview — the widget previews are arranged small, medium, large. See the warning above.
  5. Tap Add Widget.
  6. Tap Done, or tap an empty area to stop the jiggling.

Step 3 — Point the widget at the script

A freshly added Scriptable widget doesn't know which script to run yet, so it will look blank or say "Select script in widget configuration".

  1. Press and hold the new widget.
  2. Tap Edit Widget.
  3. Tap Script and choose Scripture Stories.
  4. Leave When Interacting set to Run Script.
  5. Tap outside the panel to close it.

A story should appear within a few seconds.

Optional — Show only one part of the scriptures

In the same Edit Widget panel there's a Parameter field. Leave it empty to draw from everything, or enter one of these to narrow it down:

  • old_testament
  • new_testament
  • book_of_mormon
  • church_history

You can combine them with commas and no spaces, for example old_testament,new_testament. A typo here makes the widget show an error instead of a story, so check the spelling against the list above.

Want two at once? Add a second widget and give it a different parameter — each widget keeps its own setting.

If something doesn't look right

The summary is cut off partway through.
You're on the small or medium widget. iOS can't resize a placed widget, so remove it and add the large one instead.
It says "Select script in widget configuration".
Step 3 hasn't been done yet — press and hold the widget and pick the script.
It says "Couldn't load a story".
The widget couldn't reach the API. Check your connection, then open Scriptable and run the script directly — the error it shows there is usually more specific.
The story doesn't change very often.
The script asks for a refresh about once an hour, but iOS makes the final call and will refresh less often to save battery — especially in Low Power Mode, or for a widget you rarely look at. This is normal and can't be forced from the script.
It stopped updating entirely.
Removing the widget and adding it again usually clears it. Make sure Scriptable is allowed to refresh in the background under Settings → General → Background App Refresh.
